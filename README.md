第一周
endl和\n的区别。endl和cerr都可以直接刷新缓存区。endl自带\n和刷新缓存区的2项功能。
这个例子展示endl和\n的区别：
int main() {
    cout << "第一步：准备读取数据...\n";  // 使用了 \n，进了缓冲区，但没刷新
    
    // 这里发生了一个严重的错误（比如除以 0，或者操作了非法的内存）
    int a = 10 / 0; 
    
    cout << "第二步：读取完毕！\n";
    return 0;
}
当你的程序跑起来时，实际上是这样的分工合作： 

第 1 步： CPU（工人）在车间里读到了 cout << "第一步...\n"; 这行代码。CPU 的动作是：把这串文字打包，扔到“装卸货站台”（输出缓冲区）里，等待发车。

第 2 步： 扔完包裹后，CPU 根本不关心车发了没有，它立刻转身去执行下一条代码：计算 10 / 0。

第 3 步： CPU 在车间里一算，发现数学上根本不能除以 0！这触发了操作系统的最高级别警报，系统直接“强行炸毁”了你的整个工厂（程序崩溃，进程被强制杀死）。

结局： 既然工厂都被强制拆除了，那个还停在装卸货站台上、没来得及发往屏幕的包裹（缓冲区里的文字），自然也就跟着灰飞烟灭了。


在 C++ 中，这辆“输出快递车”通常只有在以下 4 种情况下才会发车（刷新缓冲区）：

1.车满了（容量溢出）： 就像你刚才猜想的那样。

2.强制命令（手动刷新）： 你使用了 endl 或 std::flush。

3.遇到需要键盘输入时： 当代码执行到 cin >> b; 时，C++ 会非常聪明地先把 cout 快递车里的东西发走，以防你要问用户的提示语（比如 "请猜数字："）还没印出来，程序就傻乎乎地在那等输入。

4.正常下班（程序安全结束）： 当程序顺利执行到 return 0; 时，系统会把所有没发走的车全部清理发走。
